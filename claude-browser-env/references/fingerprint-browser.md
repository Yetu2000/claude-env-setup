# 指纹浏览器配置（以 AdsPower 为例）

其他指纹浏览器（比特、Hubstudio、MoreLogin、Multilogin、GoLogin 等）的选项名称不同，但含义一一对应，按本页的"推荐值"和"原因"去找对应项即可。

总原则：**跟本机真实环境一致，跟出口 IP 一致，不加随机噪音，不每次换指纹。** 指纹浏览器最容易出问题的不是"伪装得不够"，而是"伪装得太多"：系统跨平台、画布和音频加随机噪点，反而会让环境显得不真实。

## 1. 新建环境：基础设置与代理

- **名称**：填「Claude 账号」。有多个环境时加序号（Claude-1、Claude-2），方便区分。
- **浏览器**：选默认的 SunBrowser（Chrome 内核）。
- **操作系统**：按自己的真实电脑选，Mac 选 macOS，Windows 选 Windows。**不要跨系统伪装**，否则字体和渲染特征会对不上。
- **User-Agent**：范围选「全部」，自动匹配本机系统。
- **代理**（二选一）：
  - 单独绑定海外 Socks5 静态住宅代理，测试通过后再启动；
  - 或选 noproxy，走电脑上 Clash 的分流出口（第二步配好的）。

## 2. 指纹配置上半区：WebRTC、时区、地理位置、语言

- **WebRTC**：
  - 上一步单独绑了海外 Socks5 代理：选「代理 UDP」或「禁用」都可以；
  - 上一步选了 noproxy、走本机分流：**必须选「禁用」**，避免网页通过国内 STUN 服务器探测到本地宽带 IP。
- **时区、地理位置、语言**：三项都保持「基于 IP」，地理位置权限选「允许」。
- **界面语言**：开启「基于语言」。这样启动时会按出口 IP 把时区、经纬度和语言（例如 en-US）自动对齐，浏览器界面语言也跟着统一。
- **分辨率**：选「预定义 → 基于 User-Agent」；**字体**：保持「默认」。

## 3. 指纹配置下半区：关掉假噪音，硬件参数用真实值

Canvas、WebGL 图像、AudioContext 这类噪音开关打开后，浏览器每次渲染都会掺入随机噪点。带随机噪点的画布特征很容易被识别为伪造环境，同时 Cloudflare 等人机验证会频繁弹出。

- **噪音开关**：只打开「媒体设备（噪音 Auto）」；Canvas、WebGL 图像、AudioContext、ClientRects、SpeechVoices 的噪音全部关掉（选「真实」）。
- **硬件参数**：WebGL 元数据、WebGPU、CPU、RAM、设备名称、MAC 地址全部选「真实」。
- **Do Not Track**：选「默认」。

## 4. 高级设置

- **端口扫描保护**：选「启用」，防止网页探测本机开着的代理软件或开发服务端口。
- **硬件加速**：「默认」；**禁用 TLS 特性**：「关闭」，保持原生的 TLS 握手特征。
- **数据同步 / 浏览器设置**：都选「跟随全局设置」，自动保存 Cookie 和登录状态。
- **随机指纹**：**保持关闭**。打开后每次启动都换一套指纹，相当于每次换一台新电脑登录。
- 最后点底部的「确定」保存环境。

## 5. 对照表

| 配置项 | 推荐值 | 原因 |
|---|---|---|
| 名称（基础设置） | Claude 账号（多个环境加序号） | 方便区分 |
| 浏览器 / 内核 | SunBrowser（Chrome 内核） | 原生 Chromium 内核，兼容性最好 |
| 操作系统 | 按本机真实系统选 macOS 或 Windows | 避免字体和渲染特征对不上 |
| User-Agent | 范围「全部」，自动匹配本机系统 | UA 与真实系统一致 |
| 代理方式 | Socks5 静态住宅代理，或 noproxy 走本机 Clash 出口 | 固定、干净的出口 IP，测试通过再启动 |
| WebRTC | 代理 UDP 或禁用；noproxy 时必须禁用 | 防止 WebRTC 绕过代理暴露本地 IP |
| 时区 / 地理位置 / 语言 | 全部「基于 IP」，地理位置「允许」 | 与出口 IP 所在地区自动对齐 |
| 界面语言 | 「基于语言」 | 浏览器界面语言与网页语言一致 |
| 分辨率 / 字体 | 预定义 → 基于 User-Agent / 字体默认 | 避免分辨率与系统特征冲突 |
| 硬件噪音 | 只开「媒体设备：噪音 Auto」，其余全部真实 | 随机噪点会让环境显得伪造 |
| WebGL 元数据 / WebGPU / CPU / RAM / 设备名 / MAC | 全部真实 | 配合关闭噪音，指纹真实度最高 |
| Do Not Track | 默认 | 普通用户的默认状态 |
| 端口扫描保护 | 启用 | 阻止网页扫描本机代理或开发端口 |
| 硬件加速 / 禁用 TLS 特性 | 默认 / 关闭 | 保持原生 TLS 与渲染特征 |
| 数据同步 / 浏览器设置 | 跟随全局设置 | 保存 Cookie 与登录状态 |
| 随机指纹 | 关闭 | 固定设备环境，不每次换新指纹 |

## 6. 启动后核对

1. 在列表里点「启动」，AdsPower 会打开环境自检页。核对三处：
   - 顶部显示的出口 IP 和国家城市（例如 美国 / California / Los Angeles）是不是你买的那个 IP；
   - 「代理类型」是不是 Socks5（或对应的海外出口）；
   - 「指纹信息」里的操作系统（Mac OS / Windows）和语言（en-US）是否对齐。
2. 在自检页点 BrowserScan 图标，或新开标签页打开 <https://www.browserscan.net>，等几秒：
   - 「浏览器指纹真实度」应为 100%（第 3 节噪音没关时会明显偏低）；
   - IP 时区、系统时区、地理位置、语言一致；
   - 代理、机器人检测显示「否」，没有 DNS 泄漏和 WebRTC 泄漏。
3. 不满 100% 时，按 BrowserScan 标红的项目回到第 2～4 节逐项检查。

## 7. 使用习惯

- 以后用网页版 <https://claude.ai> 只在这个环境窗口里打开，不要在平时的 Chrome 或 Safari 里直接登录。
- 注册或登录用的邮箱也只在这个窗口里登录收信。优先用平时没在不干净的节点下登录过的 Gmail 或 Outlook；不要用刚注册的新 Gmail，也不要用不知名的临时邮箱；没有的话可以在这个窗口里注册 Proton（<https://proton.me/mail>，选 Free），记得先绑定一个恢复邮箱。
- 验证邮件发到日常邮箱时，**不要在日常浏览器里直接点按钮**：在按钮上右键「复制链接地址」，粘到这个环境窗口里打开。
- Claude Code 登录：终端里会打印登录链接，复制到这个环境窗口里打开完成授权。
- 电脑本身的时区仍然按出口对齐（SKILL.md 第 3 步），指纹浏览器只管它自己窗口里的时区和语言。
