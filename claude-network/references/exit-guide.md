# 出口怎么选：A（干净机房节点）还是 B（住宅 IP 链式代理）

跟用户讲的时候用下面这几段话，别堆术语。

## 先说结论

Claude 看到的是你的**出口 IP**。它最在意三件事：

1. **地区**：不能是香港、澳门、中国大陆（Claude 在这些地区不提供服务）。
2. **固定**：同一个账号今天美国、明天日本、一会儿换一个 IP，最容易被要求验证或风控。
3. **干净**：IP 没被大量人共用、没有被标成「机房 / 代理 / VPN」的坏名声。

| 你的情况 | 用哪个方案 |
|---|---|
| 有自己的 VPS，用起来 Claude 很少弹验证 | **A**：直接拿这个节点当「海外出口」 |
| 用的是普通机场：节点名一样但每次出口 IP 不同、几十上百人共用、经常要验证/被拒 | **B**：另买一个**静态住宅 IP**，让机场节点只当「跳板」，最终出口是住宅 IP |
| 只有香港 / 澳门 / 大陆中转节点 | 只能 **B**：这些节点能当跳板，不能当出口 |

## 怎么判断节点「干不干净、固不固定」

- 跑完 A 方案后，`cnet verify` 第 4 项会用 api.ipify.org、ipinfo.io、claude.ai、httpbin.org 四个地方同时看出口 IP：**不是同一个**，就说明这个节点背后是多台机器（负载均衡）或会换 IP——这种不适合当 Claude 的出口。
- 第 4 项还会附上 ip-api.com 的参考信息：`hosting=true` 表示机房 IP，`proxy=true` 表示被标记为代理。机房 IP 本身不等于不能用（很多人用自己的 VPS 很稳），但**机场的共享机房 IP** 往往名声差。
- 隔几个小时再跑一次 `cnet verify --items 4`，IP 变了就是不固定。

## B 方案：住宅 IP 怎么买、要什么

到住宅代理供应商的网站自己下单（AI 不代买、不碰你的账号密码）。下单时认准：

- **静态住宅 / Static Residential / ISP Proxy**：IP 固定不变。不要买「动态 / Rotating / 轮换」的，那种每次请求换 IP，比机场还糟。
- **地区**：美国、日本、新加坡、英国等 Claude 支持的地区，选一个就固定用它。
- **协议与认证**：支持 **SOCKS5**，用**用户名 + 密码**认证（不要只支持 IP 白名单的，除非你的跳板节点出口 IP 固定并能加白名单）。
- 买完拿到四样东西：**IP（或域名）、端口、用户名、密码**。端口不一定是 1080，以供应商面板为准。
- 「独享」和「共享」：静态 ISP 也有共享的。要更稳就选 dedicated / 独享，价格会高一些。

### 为什么需要「跳板」

住宅代理的服务器在海外，从国内直连大概率连不上或很慢。所以链路是：

```
你的电脑 → 虚拟网卡 → 跳板节点（机场节点，香港也行）→ 住宅 SOCKS5 → Claude
```

Claude 看到的是住宅 IP；跳板只负责把你送到住宅代理那里。跳板挂了可以在「跳板」组里换另一个节点，**出口 IP 不变**。住宅代理自己的地址被规则指定走跳板，不然会绕成死循环；住宅代理的 UDP 关掉（QUIC 会自动回落到 TCP）。

## 两种方案共同的保证

- 「海外出口」组是**手动选择**，里面**没有 DIRECT**：选中的出口挂了就是断网，不会偷偷换节点，更不会回落成你本地的国内 IP。
- 组里多了一个「演练-断线(勿选)」：它永远连不上，只给第 9 项演练用。误选了也只是断网，不会漏。
- 国内网站照常直连走国内线路；海外出口挂了，国内网站也照常能开。
